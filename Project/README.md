# Interactive Portfolio

This is a small interactive, responsive, animated portfolio scaffold.

Files created:

- `index.html` — main markup
- `styles.css` — styles, animations, responsive layout
- `script.js` — interactivity: mobile nav, theme toggle, modal, filters

How to run

Open `index.html` directly in a browser, or run a lightweight local server (recommended).

PowerShell (Python available):

```powershell
cd c:/Users/user/Desktop/Session/Project
python -m http.server 8000
# then open http://localhost:8000
```

Node (if you have `http-server`):

```powershell
npm install -g http-server
http-server . -p 8000
```
